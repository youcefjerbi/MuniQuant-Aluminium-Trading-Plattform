# Geographic asset dependency map

This branch adds **Asset map** independently of the research and investigation PRs. Run the README startup sequence, including `alembic upgrade head`, then open `/#map`.

The interactive Leaflet world map uses bundled Natural Earth country polygons, with pan, zoom and country-name tooltips. It requires no Google account, API key or external tile requests. This is a geographic world map, not Google Earth satellite imagery or a 3D terrain globe. Country boundaries are generalized and follow the source dataset's conventions; they are not a political or legal determination. Sources: https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/ and https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson. Natural Earth is public domain; Leaflet 1.9.4 is bundled with its license.

Select bauxite, alumina, primary aluminium, electricity or other to filter associations and their endpoints. Select an effective date to filter relationship validity. This is not point-in-time information replay: coordinates use the latest recorded location and assertions can have been recorded after their effective dates. Assets without coordinates remain listed. No country centroids or proximity-based supply links are fabricated automatically.

Register an asset location with latitude, longitude, precision, evidence document and actual/fictional classification. New location records preserve old records; latest recorded location is displayed. Register a directed dependency with its two registered endpoints, product, material/power/transport/ownership type, source document, validity interval, note and asserted/hypothesis status. Writes require Workspace access. These are curator assertions, not independently verified relationships. There is no edit/delete endpoint in this version.

Click markers or connections for details. Direction arrows and From → To listings indicate association direction. Connections are schematic, not physical roads, shipping routes, causal effects or volume estimates. Amber markers/links are fictional; dashed lines are hypotheses. Registered document inspection is available below the map. Existing ownership records are not converted automatically to material flows.

Tables `asset_location` and `asset_dependency` have coordinate/date/distinct-endpoint checks and lookup indexes. Their plant and document IDs are Data Core references: plain fields, checked through the Core API when a record is written (DC1 step B). Plant details on the map come from the Core. Map records remain separate from existing evidence export contracts. API: GET `/api/asset-map?product=alumina&as_of=2026-10-11`, POST `/api/asset-map/locations`, POST `/api/asset-map/dependencies`. Bounds: 10,000 recorded locations and 2,000 selected active dependencies. Dates are inclusive. Equal-timestamp location ties are resolved by record ID.

The map preview uses explicitly fictional locations and links; no verified global facility geography or supply network is claimed. Import actual facility coordinates and product relationships only with supporting documents. Additional gates: corrections/supersession, structured quantities, country exposure aggregates, detailed/satellite basemaps and spatial database indexing.
